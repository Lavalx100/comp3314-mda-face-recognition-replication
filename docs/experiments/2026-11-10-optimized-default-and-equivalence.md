# Optimized sweep default and targeted equivalence validation

**Run date:** 2026-11-10 (Hong Kong time)
**Status:** complete. Canonical full grids were preserved; no full grid was rerun.

## Decision

The complete five-repeat unit-L2 and within-scatter grids under results/2026-11-09-paper-proximate-full-grid* remain the canonical experimental data. They were generated by the direct implementation before the cache optimization. The optimized sweep is now the default for future dimension searches. A targeted comparison against those grids identified an intermediate cache behavior that changed a few near-singular fits; that behavior was corrected, and only the affected configurations were recomputed.

The current optimized cache reuses the first row and per-row first-column generalized eigensystem factorizations. It then forms each requested output dimension with the same shape-specific matrix multiplication as a direct fit. It does not multiply a full eigenvector basis and truncate it. This preserves finite-precision behavior while avoiding repeated scatter construction and eigendecomposition.

## Why the exhaustive rerun was stopped

An optimized unit-L2 sweep had started in results/2026-11-10-optimized-full-grid-unit-l2/. It used the same ORL archive, 64-level per-image equalization, seeds, gallery counts, dimension pairs, ridge, update order, stopping rule, and iteration cap as the canonical grid. At the user's request, it was stopped after three complete gallery-size-2 splits. The raw checkpoint contains 30,390 MDA/2-2 rows plus baseline rows; the objective checkpoint and run log are also preserved. The partial checkpoint is an audit artifact only; it is not used by tables, figures, or the report.

## Comparison that found the issue

The three completed gallery-size-2 splits (seeds 5314, 5315, and 5316) were joined to the corresponding canonical unit-L2 rows by gallery count, repeat, seed, method, row dimension, and column dimension. This gave 30,390 matched MDA/2-2 configurations.

| Comparison of initial cached checkpoint to canonical direct grid | Count |
|---|---:|
| Accuracy rows that differed | 2 |
| Stopping-iteration rows that differed | 16 |
| Final-objective relative differences above 1e-7 | 17 |
| Largest final-objective relative difference | 0.00768 |

The differences clustered in low-dimensional, gallery-size-2 fits where the within-class scatter is highly singular. Reusing a full basis and taking prefixes changed the floating-point shape of the matrix multiplication. Tiny perturbations changed tied or ill-conditioned eigendirections and could affect stopping or nearest-neighbour predictions. The optimization therefore needed to reuse factorizations, while forming each requested-size projection exactly as the direct path does.

## Targeted recheck after the correction

scripts/validate_mda_cache_equivalence.py rechecked the 17 configurations flagged by an accuracy difference, iteration difference, or objective relative difference greater than 1e-7. The checks used the original ORL data and the exact matching train/probe indices for seeds 5314–5316. We then repeated those same 17 settings under within-scatter normalization against its canonical full-grid rows using scripts/validate_mda_targeted_equivalence.py.

| Corrected cache versus direct fit | Result across 17 configurations |
|---|---:|
| Prediction mismatches | 0 |
| Accuracy mismatches | 0 |
| Iteration-count mismatches | 0 |
| Sign-aligned projection difference | 0 |
| Squared-distance difference | 0 |
| Final-objective difference, direct versus cached | 0 |
| Maximum objective relative difference, recomputed direct versus stored direct row | 1.86e-7 |

The within-scatter check also had zero prediction, accuracy, and iteration mismatches; sign-aligned projections, squared distances, and objectives were exactly equal between corrected cached and direct fits. Recomputed direct fits matched the canonical within-scatter accuracy and iteration counts for all 17 settings. The flagged configurations were selected from unit-L2 discrepancies; they are a targeted cross-normalization check, not a random sample of every grid cell.

The complete CSV-level comparison found exact agreement in accuracy and iteration counts between recomputed direct fits and the canonical rows for all 17 flagged configurations under both normalizations. The old full-grid CSVs do not store per-probe prediction vectors, so predictions were recomputed for these flagged cases and compared directly. The validation CSVs retain per-configuration prediction-mismatch counts and numerical difference metrics; they do not store full projection, distance, or prediction arrays.

The unit-L2 and within-scatter heatmaps were regenerated from their unchanged canonical `dimension_summary.csv` files. Their subtitles now label their respective normalization correctly; the earlier unit-L2 SVG had carried a stale within-scatter subtitle. No experimental scores were recalculated to make the figures.

This is targeted validation, not a second exhaustive run. The source-level correction makes the optimized cache use the same dimension-shaped projection operations for every feasible pair. The complete original results remain unchanged.

## Performance benchmark of the corrected implementation

The benchmark ran locally on the MacBook Pro Mac15,10, Apple M3 Max, 14 cores, and 36 GB unified memory. Each setting evaluated 60 representative fits over 12 dimension pairs at gallery size 5, split seed 8314. One Accelerate thread was used per fit.

| Implementation | Workers | Throughput | Peak RSS |
|---|---:|---:|---:|
| Direct | 14 | 40.50 fits/s | 1.19 GiB |
| Corrected cached | 8 | 42.88 fits/s | 0.72 GiB |
| Corrected cached | 14 | 47.48 fits/s | 0.91 GiB |
| Corrected cached | 16 | 46.91 fits/s | 0.97 GiB |
| Corrected cached | 16, BLAS 2 threads | 45.06 fits/s | 0.95 GiB |
| Corrected cached | 16, BLAS 4 threads | 45.27 fits/s | 0.91 GiB |

The best tested setting is 14 workers and one Accelerate thread. Its measured throughput is about 17% higher than the direct path at 14 workers and its peak RSS is about 0.28 GiB lower. Projecting 47.48 fits/s to 202,600 fits gives about 71 minutes, but this is an estimate from a representative batch; the full unit-L2 run previously took 2 h 19 m 40 s, and gallery-size mix can change runtime.

A fresh stage profile of 12 direct fits measured 0.530 s in scatter construction, 0.250 s in eigendecomposition, 0.435 s in other projection/iteration work, and 0.010 s in classification. Data loading and equalization took 0.054 s for the dataset.
